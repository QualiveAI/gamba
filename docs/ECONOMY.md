# Экономика WINDROP (монетки)

## Привязка к гифт-картам Roblox
- **1 золотая монетка (unit) = 1 Robux.**
- Roblox гифт-карта $10 = 800 Robux = **800 монеток**; $25 = 2000; $50 = 4000; $100 = 8000.
- Вывод — только гифт-картами: игрок выводит сумму монеток, получает карту соответствующего
  номинала. Мин. вывод = 800 монеток (карта $10).
- Ориентир фиата: 1 монетка ≈ $0.0125 (курс Robux), т.е. 100 монеток ≈ $1.25.

## Две валюты
| Валюта | Внутр. код | Что это | Вывод |
|---|---|---|---|
| 🪙 Золотые монетки | `units` | основная валюта, депозиты (Stars/крипта/карты) | да, гифт-картами |
| 🥉 Медные монетки | `freebets` | фрибеты: бонусы, миссии, фрибет-кейсы | нет, конвертация 100:1 |

- **Конвертация меди в золото: 100 🥉 → 1 🪙** (эндпоинт `/rewards/convert_freebets`).
- Фрибет-кейсы внутри «сильно нищие»: 500 медных фрибетов превращаются примерно в 4.5–5 золотых.

## Лестница кейсов (цены в золотых монетках)
Кейсы — по топовым играм внутри Roblox, от нищих к богатым:
Blox Fruits 50 → Adopt Me 80 → Brookhaven 120 → Arsenal 150 → Pet Sim 99 200 →
Jailbreak 350 → Murder Mystery 2 600 → Tower of Hell 1000.

## Предметы и вывод
- Каждая награда кейса = **предмет с ценой в монетках** (поле `label` + `nominal_units`).
- При открытии на баланс падает цена предмета (проверно fair: seed hash + nonce в case_openings).
- При выборе вывода игрок видит цену каждого предмета/суммы и **гифт-карту какой игры** получит
  (Roblox, а далее — по мере подключения игр: Steam, PSN, Google Play...).
- Сумма вывода → номинал карты: 800 монеток = $10, 2000 = $25, 4000 = $50, 8000 = $100.

## RTP
- Базовый RTP 90%, модификаторы f_win/f_bet/f_chase, сегменты new/active/veteran
  (new 0.95 / active 0.88 / veteran 0.85), клампа 80–95% — без изменений.
- Ожидание игрока: открыл кейс за X монеток → предмет ценой в среднем 0.88–0.95·X.
