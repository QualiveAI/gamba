# Currency

## Dual-currency model

units real, freebets bonus.

## Invariants

sum(delta) per currency == balance. Cross-currency forbidden.

## Reasons

welcome_freebet, daily_freebet, etc.

## Why freebets can't leak

Ledger enforces currency. Withdrawal only units.
