## Высокий приоритет

0. **Уроки musodrop.com (референс, CS2-кейсокрутилка)** — уже учтено: коллекции кейсов по
   уровням и темам; **50/50-кейсы** (шанс 50% на конкретный топ-предмет) — сделать
   отдельный тип кейса; **микро-кейсы от 0.25** — у нас минимум 25 монеток, добавить
   кейсы за 5-10; Mystery Box («худший или лучший») как формат; **контракты**
   (N предметов -> один дорогой) — после апгрейдера; отдельная страница «Проверка
   честности» + статьи блога; footer с юрлицом; Telegram-каналы поддержки/дропов.
1. **Картинки кейсов и предметов** — сейчас эмодзи. Нужны PNG/WebP (см. docs/ASSETS_NEEDED.md).
2. **Звуки**: прокрутка рулетки, клик стопа, фанфары легендарки + тумблер mute.
3. **Скретч/конфетти при дропе Epic+** (canvas particles поверх результата).
4. **Дешёвые кейсы для новичков** (10–25 юнитов) — у лидеров вход от $0.5, у нас от 100.
5. **Upgrade-игра с колесом** как в Key-Drop (сейчас голая математика).
6. **Дроп-фид с именами/аватарами** (сейчас суммы без имён) + подсветка своего дропа.

## Средний
7. **Мульти-открытие** (x2/x3/x5 сразу) — повышает средний чек у всех лидеров.
8. **Битвы кейсов** (case battles 1v1/2v2) — главная соц-фича ниши, следующий большой этап.
9. **Provably fair страница** — показать server_seed_hash/nonce клиенту после дропа (данные уже в API).
10. **Daily free case + rakeback** (у нас есть rewards-модули — связать с UI).
11. **Поиск/фильтр кейсов по игре и цене**, сортировка.
12. **История своих открытий** на экране wallet.

## Низкий
13. Контракты (trade-up) между предметами одной редкости.
14. Сезонные кейсы (хэллоуин/новогодние) через case builder без кода.
15. Партнёрская витрина топ-дропов за 24ч.

## Технический долг, замеченный при проходе
- conftest стирает ВСЕ таблицы на каждый прогон тестов — сиды нужно запускать после тестов
  (или сделать флаг KEEP_DB / отдельную тестовую БД).
- list_cases не отдаёт game_key кейса (badge берётся из первой награды — костыль).
- /meta/cases (старый каталог) дублирует /cases — унифицировать.
