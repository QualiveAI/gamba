# Predictor Anti-Pattern Preview

## Назначение

`predictor-preview/` — локальная статическая демонстрация идеи сервиса-предсказателя для Minas, Crash/Foguete и Copos. Она сделана, чтобы увидеть визуальное поведение и отказаться от нечестной модели до подключения к WINDROP.

Preview намеренно показывает два режима:

- **Anti-pattern** — качество synthetic signal искусственно выше для низкой ставки и ниже для высокой;
- **Baseline** — одинаковое нейтральное качество без передачи размера ставки в анализ.

Это демонстрация проблемы, а не рабочий predictor. Код не подключён к `frontend/`, backend, Telegram, кошельку, БД, платежам или live sessions.

## Запуск

```bash
python -I -m http.server 4180 --bind 127.0.0.1 --directory predictor-preview
```

Открыть: `http://127.0.0.1:4180/`

## Что проверять

- переключить Minas / Crash / Copos;
- сравнить режимы Anti-pattern и Baseline при одном seed;
- поменять диапазон ставки и увидеть искусственное расхождение качества;
- посмотреть таблицу ошибок/вредных советов и график;
- проверить mobile viewport.

Все данные deterministic и synthetic. Нет платежной кнопки, Telegram URL, API URL, session/user IDs, wallet или outcome mutation.

## Почему это нельзя подключать к продукту

Если качество сигнала меняется от размера ставки, сервис выборочно ухудшает опыт крупного игрока и не является честным анализом. Реальный безопасный продукт может показывать только:

- provably-fair verification;
- историческую статистику;
- квантильные вероятности;
- учебный симулятор;
- risk/18+ disclosures.

Он не должен обещать следующий исход, менять игровой результат или продавать намеренно ошибочные сигналы.
